Comment jouer : Distinction

Les questions de distinction commencent par des prémisses qui définissent les relations entre plusieurs éléments. Par exemple :

  • Abricot est identique à Gobelet
  • Rameau est identique à Abricot
  • Gobelet est identique à Robinet
  • Rameau est l'opposé de Robinet

À partir de votre analyse, le jeu peut vous demander d’évaluer un énoncé comme :

Conclusion : "Abricot est l'opposé de Robinet."

À partir de votre analyse, appuyez sur Vrai si vous estimez que la relation donnée est correcte, ou sur Faux si vous pensez que non.

The Inversion Cue

Lorsqu’un fragment apparaît surligné en rouge, c’est le signe qu’il faut inverser mentalement l’information présentée.
